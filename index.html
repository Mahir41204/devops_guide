Phase 1 Foundations — Linux, Networking and Git Months 0 to 4 · ~400 hrs ▶
Prerequisites for Phase 1
Basic programming
Bash scripting equals programming: loops, conditionals, functions, and variables are required.
  • CS50P (Harvard, free)
OS concepts
Processes, file descriptors, and signals make Linux commands make sense.
  • OSTEP (free book)
YAML and JSON fluency
Config files for cloud, tooling, and scripts require fast, accurate edits.
  • Learn YAML in Y minutes
Linux and Bash
Tools: Ubuntu, Bash, Vim or Nano
Deep
File system, permissions, processes, cron, shell scripting. This is your daily environment — invest heavily here.
Networking basics
Tools: curl, netstat, dig, Wireshark
Working
TCP/IP, DNS, HTTP/S, ports, firewalls, load balancing concepts, NAT, subnets, VPNs.
Git and version control
Tools: Git, GitHub or GitLab
Deep
Branching, merging, rebasing, PRs, tagging, Git hooks, monorepo vs polyrepo. Core skill.
Scripting (Python or Go)
Tools: Python 3, Go
Working
Automate repetitive tasks. Python is faster to pick up; Go is preferred in cloud-native tooling later.
Cloud fundamentals (one provider)
Tools: AWS, GCP, or Azure free tier
Awareness
EC2 or VMs, S3 or Blob storage, IAM, billing. Pick AWS first for market share.
How software is built and deployed
Tools: Make, npm, pip, Maven
Awareness
Understand build systems, artifacts, dependency managers. You serve developers — know how they work.
Milestone: Comfortable in a Linux terminal, can write useful shell scripts, understand how a web request travels end-to-end. Resources: Linux Journey, The Odin Project, Pro Git book (free).

Hands-on projects for Phase 1
P1
Automated server setup script
Write a Bash script that provisions a fresh Ubuntu VM: installs packages, creates users, sets up firewall rules (ufw), and configures SSH key-only auth. Run it on a free-tier EC2 instance.
P2
Git branching strategy simulation
Create a mini app repo, implement GitFlow with feature branches, PRs, tags, and a mono-repo layout. Practice rebase, cherry-pick, and merge conflict resolution deliberately.
P3
Network packet inspector
Use Wireshark and tcpdump to capture HTTP vs HTTPS traffic, DNS queries, and a TCP handshake. Document what you observe; explain each layer. Bonus: run a local DNS server (dnsmasq).
P4
Python log analyzer
Parse nginx or Apache access logs with Python, extract top IPs, status codes, and request rates. Output a summary report. Schedule via cron.
P5
Static website on AWS S3 and CloudFront
Host a static site on S3, front it with CloudFront (HTTPS), set up a custom domain with Route 53. Connects cloud fundamentals with real deployment concepts.

Hands-on projects for Phase 2
P1
Dockerise a multi-service app
Take a Node.js or Python app with a Postgres DB and Redis cache. Write Dockerfiles, compose them with docker-compose, optimize image size, set up health checks and restart policies.
P2
Full CI/CD pipeline with GitHub Actions
Build a pipeline that lints, runs tests, builds a Docker image, pushes to ECR or Docker Hub, and deploys to an EC2 or ECS instance — with environment-based secrets.
P3
Terraform AWS infrastructure
Provision a full VPC: subnets, security groups, EC2 instances behind an ALB, RDS in a private subnet, and an S3 bucket. Use modules and remote state (S3 + DynamoDB lock).
P4
Ansible server hardening playbook
Write an Ansible playbook that hardens multiple EC2 instances: disables root login, configures fail2ban, updates packages, deploys an Nginx config from a template, and manages users idempotently.
P5
Approval-gated staging to production pipeline
Extend the CI/CD pipeline with a manual approval gate between staging and production. Add automated smoke tests post-deploy and Slack notifications on success or failure.

P1
Production-grade EKS cluster with Terraform
